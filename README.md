# СПЕКТР — премиальный лендинг

Одностраничный сайт ООО «СПЕКТР» (Магнитогорск): установка и остекление балконов,
окна ПВХ, комплексный ремонт под ключ. На рынке с 2018 года.

Минималистичный «бумажный» стиль, крупная типографика Inter Tight, фирменный
акцент — тонкий спектральный градиент (свет, преломлённый стеклом).

## Технологии

- **Three.js** — фоновый шейдер «преломлённый свет»: мягкие пастельные пятна
  спектра дрейфуют по странице, отвечают на скролл и курсор.
- **GSAP + ScrollTrigger + SplitText** — scroll-scrub hero-видео (короткий пин
  на два «такта», чтобы не утомлять), line-reveal заголовков, счётчики,
  спектральная линия прогресса в этапах.
- Hero-видео сгенерировано в Higgsfield (Veo 3.1 → апскейл ByteDance до 1080p).

Все библиотеки и шрифты лежат локально в `assets/` — внешних CDN для кода нет.

## Структура

```
index.html            — разметка
assets/style.css      — стили
assets/app.js         — three.js-фон + GSAP-хореография
assets/vendor/        — three.min.js, gsap.min.js, ScrollTrigger, SplitText
assets/fonts/         — Inter Tight Variable + Manrope (woff2, кириллица/латиница)
assets/hero.mp4       — (опционально) локальная копия hero-видео
```

## Hero-видео

Плеер пробует источники по порядку:

1. `assets/hero.mp4` — локальный файл (в репозитории его нет);
2. CDN-ссылка Higgsfield — работает из коробки;
3. если оба недоступны — тёмный графитовый фолбэк, сайт полностью рабочий.

Чтобы сайт был автономным, скачайте видео (1080p) и положите рядом:

```
curl -o assets/hero.mp4 "<URL из <source> в index.html>"
```

## Запуск

Открыть `index.html` в браузере или положить папку на любой статический хостинг.
