# Ascend CRM — лендинг

Минималистичная инфо-страница Ascend CRM в фирменном стиле [Ascend Systems](https://ascendsystems.ru/).
**Весь сайт — один автономный файл `index.html`**: разметка, стили и scroll-cinematic движок внутри.
Янтарная «живая лента» рисуется на канвасе кодом в реальном времени — никаких внешних файлов
не нужно, страница работает даже при открытии двойным кликом.

## Структура

```
index.html     — весь сайт (можно деплоить один этот файл)
assets/og.jpg  — превью для соцсетей (опционально, путь указан в og:image)
```

## Запуск

Открыть `index.html` в браузере — или положить на любой статический хостинг.

## Кнопка «Войти»

Все кнопки входа ведут на `login.html`. Положите рядом страницу входа CRM
под этим именем — или замените адрес поиском по `login.html` в `index.html`.

## Настройка ленты

Палитра и геометрия — в блоке `<script>` файла `index.html`:
`PALETTE` (цвета нитей), `SCENE_CFG` (число нитей на сцену), `threadY()` (форма лент
для сцен hero / flow / rise).
